**Description:**

A payment application that allows users to select between Credit Card, PayPal, and Cash payments. It demonstrates polymorphism by using the same `pay()` method across different classes, each implementing its own payment behavior.

**How to use it:**

Run:
    python payment_system.py


**Example interaction:**


===== PAYMENT SYSTEM =====
1. Credit Card
2. PayPal
3. Cash
4. Exit

Choose payment method: 2
Enter payment amount: 250

Processing PayPal payment...
Paid 250.00 using PayPal!
