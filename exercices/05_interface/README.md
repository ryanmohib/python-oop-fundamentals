**Description:**

An interactive notification application that allows users to send a message through Email, SMS, or Push Notification. It demonstrates interface-like behavior using an abstract base class that requires all notification classes to implement `send()`.


**How to use it:**

Run:
    python notifications_system.py


**Example interaction:**


===== NOTIFICATION SYSTEM =====
1. Email
2. SMS
3. Push Notification
4. Exit

Choose notification method: 1

Enter your message: Your order has been shipped!

Sending Email...
Email content: Your order has been shipped!
Email sent successfully!

**NOTE!**

*These payment and notification applications simulate their operations; they don't connect to actual payment providers or messaging services.*
