**Description:**
A simple employee management application that allows users to create regular employees and managers. It demonstrates inheritance by reusing common employee attributes and methods in the `Manager` class.

**How to use it:**

Run:
    python employee_management.py

**Example interaction:**

1. Add Employee
2. Add Manager
3. Display All Employees
4. Exit

Choose an option: 2

Manager name: Sarah
Manager salary: 8000
Manager bonus: 2000
