**Description:**

An interactive animal system that allows users to select an animal and hear its sound. It demonstrates abstraction by defining an abstract `Animal` class that requires every animal to implement the `make_sound()` method.

**How to use it:**

Run:
    python animal_system.py

**Interaction Example:**

===== ANIMAL SOUND SYSTEM =====

Choose an animal:

1. Dog
2. Cat
3. Cow
4. Duck
5. Exit

Your choice: 1

You selected: Dog
Sound: Woof! Woof!
