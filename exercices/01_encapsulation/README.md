**Description:**

A simple banking application that allows users to deposit money, withdraw money, and check their balance. It demonstrates encapsulation by protecting the account balance using a private attribute and controlling access through methods.

**How to use it**

Run:
python bank_account.py

_Example interaction:_

Enter account holder name: Adam

1. Deposit money
2. Withdraw money
3. Check balance
4. Exit

Choose an option: 1
Enter deposit amount: 1000
Successfully deposited: 1000.00

Choose an option: 2
Enter withdrawal amount: 300
Successfully withdrawn: 300.00

Choose an option: 3
Account holder: Adam
Current balance: 700.00
